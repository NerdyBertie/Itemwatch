# ItemWatch

## v2.2.4

### New
- ItemWatch now has its own icon in the AddOn List and an entry in the addon dropdown next to the minimap (left-click shows/hides the box, right-click opens settings).
- Settings now live under NerdyBertie's Addon Workshop in Options > AddOns.
- Update notices are now a clickable chat link instead of a pop-up window.
- Marked compatible with the WoW Forever beta (untested so far, so please report anything that looks off).

### Fixed
- The "Add to Shopping List" button no longer appears on Death Knight Runeforging or other windows with no reagents.
